# Security

helix-action welcomes reports of security issues in this repository.

## Report

Write to [contact@synapticfour.com](mailto:contact@synapticfour.com). Include the repository name, the commit or version, and enough detail to reproduce the issue.

Do not open a public issue for an unfixed vulnerability. Do not include credentials, personal data, or patient data in the report.

## Scope

In scope: `action.yml`, `scripts/`, and the tests in this repository.

Out of scope: a defect in [Helix](https://github.com/SynapticFour/Helix) or [HelixTest](https://github.com/SynapticFour/HelixTest) belongs in that repository. A defect in a stack this action only calls belongs with the stack.

## Response

Synaptic Four reads reports sent to the address above. This page does not promise a time.

A fix, when one is made, is noted in [CHANGELOG.md](CHANGELOG.md).
